# Dynamic To-Do List Web App

A fully responsive Dynamic To-Do List Web Application built using **HTML5, CSS3, and Vanilla JavaScript (ES6+)**.

This application helps users manage their daily tasks. Users can add, edit, delete, complete, filter, and organize tasks. The application uses **LocalStorage** to save tasks and the selected theme, so the data remains available after refreshing the page.

## Features

* Add new tasks
* Edit existing tasks
* Delete tasks
* Mark tasks as completed or uncompleted
* Filter tasks by:

  * All
  * Pending
  * Completed
* Display task statistics:

  * Total tasks
  * Completed tasks
  * Pending tasks
* Form validation to prevent empty tasks
* Display an empty-state message when there are no tasks
* Dark Mode and Light Mode
* Save tasks using LocalStorage
* Save the selected theme using LocalStorage
* Fully responsive design for desktop, tablet, and mobile devices

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file.
4. Run the project using the Live Server extension.

You can also open `index.html` directly in a web browser.

## How the Application Works

### Add a Task

Enter a task in the input field and click the **Add Task** button.

### Edit a Task

Click the **Edit** button to change an existing task.

### Delete a Task

Click the **Delete** button to remove a task.

### Complete or Uncomplete a Task

Use the checkbox to mark a task as completed or pending.

### Filter Tasks

Use the filter buttons to display:

* All tasks
* Pending tasks
* Completed tasks

### Dark and Light Mode

Click the theme button to switch between Dark Mode and Light Mode.

The selected theme is saved in LocalStorage.

### LocalStorage

Tasks are saved in the browser using LocalStorage. This means tasks remain available even after refreshing the page.
